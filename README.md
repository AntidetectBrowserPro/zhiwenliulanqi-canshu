# 如何设置浏览器语言、时区和屏幕尺寸？

用 **「指纹浏览器」** 验收德语页面时，如果菜单已变成德语，订单日期却仍跨错一天，可以先分别看「网络与地区」里的语言和时区。再把窗口缩窄，单独检查小屏排版。这三步对应三种不同的问题。

| 项目 | 网页可观察的例子 | 适合检查什么 |
| --- | --- | --- |
| 语言 | 浏览器首选语言，如 zh-CN | 页面是否采用期望的默认语言 |
| 时区 | 日期格式化器使用的时区，如 Asia/Shanghai | 同一时刻在页面上显示的本地日期 |
| 屏幕宽度 | screen.width，单位为 CSS 像素 | 浏览器报告的屏幕宽度 |
| 窗口宽度 | 当前布局视口的宽度 | 窗口变窄后菜单何时折叠 |

## 从配置页读到检测结果

指纹浏览器的电脑端把设备和屏幕放在「设备身份」，语言与时区在「网络与地区」。先记录原值，每次只调整一项，保存并按提示重启环境。随后在同一个环境打开检测页，分别核对配置值与页面读数。[官方设备身份教程](https://zwbrowser.com/help/desktop/fingerprint/)

![设备身份面板中的屏幕参数](https://zwbrowser.com/images/desktop-guide-identity-light.webp)

## 做一个能解释的对照

在相同环境里把窗口宽度缩小，再刷新自己的测试页。视口会随窗口改变，屏幕宽度可能保持原值。这个例子能帮助区分响应式布局问题与设备配置问题。若测试日期，固定同一时刻并选择接近午夜的样例，更容易观察跨日变化。[MDN 对屏幕宽度的说明](https://developer.mozilla.org/en-US/docs/Web/API/Screen/width)
